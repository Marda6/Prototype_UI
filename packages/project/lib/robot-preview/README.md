# CAM Robot Preview

Самостоятельное 3D-превью из прототипа окна **Approach / Return**. Сохранены тёмная сцена, оранжевый робот, оснастка, сетка, подсветка траектории и вращение камеры.

Работает на обычном **JavaScript + Canvas 2D**, без Three.js, внешних моделей, CDN и обязательной сборки. Геометрия трёхмерная; на Canvas она выводится через ортографическую проекцию и сортировку граней по глубине.

## Открыть пример

Распакуйте архив и откройте `demo.html` в браузере. Держите рядом `robot-preview.global.js`: это готовая версия для обычного `<script>`, которая не требует локального сервера.

В примере можно менять A1–A6 / E1–E2, проигрывать движение, перематывать, выбирать участок траектории и получать снимок текущей позы. Элементы управления и проигрыватель написаны в `demo.html`; сам модуль отвечает за сцену.

## Что переносить

| Файл | Назначение |
| --- | --- |
| `robot-preview.js` | Основной исходный код, ES module. Подходит для проектов с `import`, в том числе React и Vue. |
| `robot-preview.d.ts` | Типы TypeScript. Положите рядом с основным модулем. |
| `robot-preview.global.js` | Тот же код для обычного `<script>`. Экспортирует `window.CamRobotPreview`. |
| `demo.html` | Рабочий пример интерфейса, проигрывания и снимка позы. |
| `build-global.mjs` | Необязательный скрипт: пересобирает классическую версию после правок основного кода. |
| `package.json` | Обозначает ES module и файл типов. Зависимостей нет. |

В другой проект достаточно перенести **одну версию рендера**: `robot-preview.js` или `robot-preview.global.js`. У модуля нет привязки к ID элементов, редактору команд или CSS исходного окна; можно создать несколько независимых экземпляров.

## Подключение через import

Контейнеру нужна явная высота. Пример ниже работает в приложении со сборщиком или при открытии HTML через HTTP; для открытия двойным кликом используйте классическую версию из следующего раздела.

```html
<div id="robot-view" style="width: 100%; height: 440px; overflow: hidden;"></div>

<script type="module">
  import { RobotPreview, DEFAULT_POSE } from './robot-preview.js';

  const from = { ...DEFAULT_POSE };
  const to = { ...from, A1: 0, A2: -45, A3: 90, A4: 0, A5: 45, A6: 0 };

  const preview = new RobotPreview(document.getElementById('robot-view'), {
    pose: from,
    segments: [{ id: 'step-1', from, to }],
    selectedSegmentId: 'step-1',
    onSegmentSelect(id) {
      console.log('Выбран участок:', id);
      // Здесь можно выделить соответствующую команду в вашем редакторе.
    },
  });

  preview.setPose({ A2: -60 });
  // При удалении экрана / компонента вызовите preview.destroy().
</script>
```

## Подключение обычным script

```html
<div id="robot-view" style="height: 440px;"></div>
<script src="./robot-preview.global.js"></script>
<script>
  const preview = new CamRobotPreview.RobotPreview(
    document.getElementById('robot-view')
  );
  preview.setPose({ A1: 15, A2: -60 });
</script>
```

Не подключайте обе версии одновременно в одном приложении. После изменения `robot-preview.js` классическую версию можно обновить командой `node build-global.mjs` из папки комплекта. Установка npm-пакетов для этого не нужна.

## API

| Вызов | Поведение |
| --- | --- |
| `new RobotPreview(container, options?)` | Создаёт Canvas внутри DOM-контейнера. |
| `setPose({ A2: -60 })` | Обновляет переданные оси. Остальные сохраняются. Камера остаётся на месте. |
| `getPose()` | Возвращает независимую копию всех восьми осей. Используйте для Add current state. |
| `setSegments([{ id, from, to }], { fit: true })` | Заменяет траекторию; по умолчанию вписывает её и сбрасывает масштаб на 1. `fit: false` сохраняет текущий вид. |
| `setSelectedSegment('step-1')` | Подсвечивает участок, не меняет позу. `null` снимает выделение. Не вызывает callback. |
| `setCamera({ yaw, pitch, zoom })` | Принимает любую часть настроек камеры. Углы — радианы. |
| `getCamera()` | Возвращает копию настроек камеры. |
| `fitToView()` | Вписывает текущую позу и выборку промежуточных поз траектории, сохраняя направление камеры. |
| `setVisibility({ grid: false, axes: true, trajectory: true })` | Показывает или скрывает указанные элементы. |
| `resize()` | Повторно измеряет размер. Обычно вызывается автоматически через ResizeObserver. |
| `destroy()` | Удаляет Canvas, обработчики событий и наблюдатель размера. Повторный вызов допустим. |
| `interpolatePose(from, to, t)` | Возвращает позу между двумя полными позами, `t` ограничивается диапазоном 0…1. |
| `getToolPosition(pose)` | Возвращает `[x, y, z]` кончика инструмента в системе условной сцены. |

`setPose()` перерисовывает сцену сразу. Внутри рендера нет постоянно работающего `requestAnimationFrame`: цикл воспроизведения создаёт ваш проект. Размер Canvas учитывает плотность пикселей; по умолчанию DPR ограничен значением 2.

### Настройки конструктора

```js
const preview = new RobotPreview(container, {
  pose: { A2: -60 },         // Остальные оси берутся из DEFAULT_POSE.
  segments: [],
  selectedSegmentId: null,
  camera: { yaw: -0.68, pitch: 0.49, zoom: 1 },
  interactive: true,        // Мышь, колесо и клавиатура.
  trajectorySamples: 28,   // 2–240 интервалов на участок.
  pixelRatioCap: 2,         // Ограничивается диапазоном 1–4.
  onSegmentSelect: id => console.log(id),
  ariaLabel: 'Превью движения робота',
});
```

`pitch` ограничен диапазоном 0.08…1.2, `zoom` — 0.5…3. Кнопка мыши / касание и перетаскивание вращают сцену, колесо меняет масштаб. При фокусе на Canvas стрелки вращают сцену, `+` и `−` меняют масштаб, `F` вписывает её.

Клик по траектории выделяет участок и вызывает `onSegmentSelect(id)`. Участки можно выбирать и из вашего списка команд через `setSelectedSegment()`. Обработку списка, переход к нужному времени и изменение позы задаёт приложение.

### Формат позы и траектории

```js
const pose = {
  A1: 5.153, A2: -78.774, A3: 117.061,
  A4: 24.299, A5: 34.839, A6: -100.39,
  E1: 0, E2: 0,
};

const segment = {
  id: 'command-42',          // Уникальная непустая строка.
  from: { ...pose },         // Все 8 осей обязательны.
  to: { ...pose, A2: -45 },
};
```

Значения осей — конечные числа, в этой модели **все углы в градусах**. Строки вроде `"45"`, `NaN`, неизвестные оси и повторяющиеся ID отклоняются с ошибкой. Начальные данные и позы копируются: изменение исходного объекта после вызова не меняет сцену. Для обновления используйте API.

Для `setPose()` допустима частичная поза. Для `from`, `to`, `interpolatePose()` и `getToolPosition()` нужны полные позы; удобно создавать их через `{ ...DEFAULT_POSE, A1: 20 }`.

## Подключить воспроизведение

Полный пример с паузой и перемоткой находится в `demo.html`. Минимальный цикл для одного участка:

```js
import { interpolatePose } from './robot-preview.js';

// preview, from и to — из примера подключения выше.
const durationMs = 3000;
let frame = 0;
const startedAt = performance.now();

function tick(now) {
  const t = Math.min(1, (now - startedAt) / durationMs);
  preview.setPose(interpolatePose(from, to, t));
  if (t < 1) frame = requestAnimationFrame(tick);
}
frame = requestAnimationFrame(tick);

// При закрытии экрана:
// cancelAnimationFrame(frame);
// preview.destroy();
```

`destroy()` очищает ресурсы рендера. Внешний цикл анимации нужно остановить отдельно. После `destroy()` не вызывайте методы изменения состояния; для повторного открытия создайте новый экземпляр. `resize()` после удаления безопасно ничего не делает.

## React

Компонент принимает готовую `pose`, поддерживает обновление параметров и освобождает ресурсы при размонтировании. Массив `segments` стоит стабилизировать через `useMemo`, чтобы не пересчитывать траекторию на каждом кадре.

```jsx
import { useEffect, useRef } from 'react';
import { RobotPreview } from './robot-preview.js';

const EMPTY_SEGMENTS = [];

export function RobotView({ pose, segments = EMPTY_SEGMENTS, onSegmentSelect }) {
  const host = useRef(null);
  const instance = useRef(null);
  const callback = useRef(onSegmentSelect);

  useEffect(() => { callback.current = onSegmentSelect; }, [onSegmentSelect]);

  useEffect(() => {
    const preview = new RobotPreview(host.current, {
      onSegmentSelect: id => callback.current?.(id),
    });
    instance.current = preview;
    return () => {
      preview.destroy();
      instance.current = null;
    };
  }, []);

  useEffect(() => {
    if (pose) instance.current?.setPose(pose);
  }, [pose]);

  useEffect(() => {
    instance.current?.setSegments(segments);
  }, [segments]);

  return <div ref={host} style={{ width: '100%', height: 440, overflow: 'hidden' }} />;
}
```

В приложении с SSR создавайте экземпляр после появления DOM, как в `useEffect` выше. Сам импорт файла не обращается к `window` или `document`. В Vue схема та же: создание в `onMounted`, обновления через `watch`, очистка в `onBeforeUnmount`.

## Границы модели и точки расширения

Это тот же схематичный робот из UX-прототипа. Длины звеньев заданы в миллиметрах; оси и размеры условные и не описывают конкретный промышленный робот. E1 вращает основание, E2 наклоняет оснастку; в реальном проекте внешние оси могут иметь другую механику и единицы.

Движение строится линейной интерполяцией углов: переход 170° → −170° идёт через 0°, без автоматического выбора кратчайшего оборота. Ось A6 вращается вокруг продольной оси симметричного инструмента, поэтому в этой геометрии её изменение может быть визуально незаметно. Перемещение E2 меняет положение оснастки, не мировую траекторию кончика инструмента.

Модуль не интерпретирует GOTO / MULTIGOTO / PHYSICGOTO, LCS / TCPM и M0 / M1. Приложение преобразует команды в позы и участки, управляет остановками и передаёт результат рендеру. Расчёта обратной кинематики, ограничений суставов, коллизий и связи со станком здесь нет.

Траектория рисуется поверх геометрии для читаемости; это не проверка видимости или столкновений. Подбор кадра учитывает дискретную выборку промежуточных поз, а не непрерывную проверку всех положений.

Для изменения внешнего вида редактируйте `COLORS`. Для другой кинематики — `buildRobot()`. Для другой оснастки — `buildScene()`, `fixtureTransform()` и соответствующие границы в `poseBounds()`. Для загрузки CAD-моделей и точной симуляции потребуется отдельный движок; текущий API можно сохранить как интерфейс интеграции.

## Проверка перед переносом

Откройте `demo.html`, измените A2, проиграйте оба участка, сделайте снимок позы и измените размер окна. В вашем приложении проверьте, что контейнер имеет ненулевую высоту, повторное открытие экрана создаёт один Canvas, а при закрытии вызывается `destroy()` и останавливается ваш проигрыватель.
