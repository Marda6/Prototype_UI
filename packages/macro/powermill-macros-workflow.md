# Макросы в PowerMill (Autodesk) — воркфлоу

> Референс для переработки прототипа макросов ENCY.
> Источник: официальная документация Autodesk (PowerMill Reference Help, Macro Programming Guide).
> Собрано: 2026-09-18.

PowerMill — CAM/ЧПУ-система (прямой аналог области ENCY). Макросы здесь — это
**командные текстовые файлы `.mac`**, а не визуальный двухколоночный список, как в Photoshop.
Это принципиально другая модель, полезная для сравнения.

---

## 1. Модель данных: команды, а не «шаги-объекты»

```
Macro (.mac файл)  →  строки-команды (текст)
```

- Макрос — это **последовательность команд PowerMill** в текстовом файле с расширением `.mac`.
- Каждое действие в интерфейсе = одна или несколько текстовых команд
  (напр. `FORM BLOCK`, `EDIT BLOCK RESET`, `BLOCK ACCEPT`).
- Команды **не чувствительны к регистру**: `FORM BLOCK` = `Form Block` = `foRm bLock`.
- Записанные макросы появляются в узле **Macro** в дереве проекта (Explorer).
- Макрос можно **вызвать из другого макроса** (вложенность / переиспользование).
- Комментарии — через `//` (можно временно отключать части макроса при отладке).

> Ключевое отличие от Photoshop: там шаг — это объект с параметрами и двумя тумблерами;
> здесь шаг — это строка текста. Редактирование = правка текста в редакторе.

---

## 2. Echo Commands — «увидеть, что делает интерфейс»

Центральная фича, которой нет прямого аналога в Photoshop:

- **Home tab → Macro panel → Echo Commands** — включает вывод всех выполняемых команд
  в командное окно (Command Window).
- Позволяет **перед записью** посмотреть, какие именно команды порождает каждое действие,
  и потом их удобно править.
- Часто используется и внутри макросов — для обратной связи пользователю,
  вывода информации или запроса ввода.

## 3. Полный воркфлоу

### 3.1. Запись (автоматическая)
1. ПКМ по узлу **Macros** в Explorer → **Record**.
2. В диалоге *Select Record Macro file* выбрать папку, задать имя → **Save**.
3. С этого момента **каждое действие** в PowerMill пишется в `.mac`-файл.
4. **Stop** — остановить запись.

### 3.2. Сборка вручную (из echoed-команд)
Типичный «профессиональный» путь — не запись, а ручная сборка:
1. **View tab → Window panel → User Interface → Command Window** — открыть командное окно.
2. Включить **Echo Commands**, выполнить действие (напр. открыть Block → Calculate → Accept).
3. Прочитать команды в квадратных скобках (`\r` игнорируется) — напр.
   `FORM BLOCK`, `EDIT BLOCK RESET`, `BLOCK ACCEPT`.
4. Скопировать нужные строки в текстовый редактор (WordPad), сохранить как `.mac`.
   Макрос появится в дереве.

### 3.3. Запуск (playback)
- **Run** → диалог *Select Macro To Run* → выбрать файл → **Open**.
- Из командной строки с аргументами: `MACRO example.mac 2`
  (макросы принимают параметры).

### 3.4. Отладка / пошаговый прогон — Macro Debugger
Введён в PowerMILL 2012 R2 (заменил старый *Step Through Macro*).
Открытие: **Home → Macro → Run → Debug** или ПКМ по макросу → **Debug**.

Окно отладчика:
- **левая панель** — текст макроса;
- **правая панель** — значения переменных в текущей точке.

Контролы:
| Контрол | Что делает |
|---|---|
| **Add breakpoint** | Точка останова в начале выбранной строки — макрос останавливается здесь. Можно ставить несколько. Особенно полезно в циклах: breakpoint в конце цикла показывает, как меняются переменные на каждой итерации. |
| **Execute** | Выполнить макрос **до ближайшего breakpoint** — довести состояние до интересующей точки. |
| **Step out** | Выполнить текущую строку и все последующие в блоке; на выходе из блока — ждать. |
| **Skip next line** | Пропустить следующую строку без выполнения (удобно для долгих расчётов — но **опасно**, если дальше нужен результат пропущенной команды). |
| Watch variables | Правая панель непрерывно отслеживает значения переменных. |

Рекомендованный порядок отладки: расставить breakpoint'ы в интересных местах →
**Execute** до нужной точки → дальше идти по строкам через Step-функции.

## 4. Служебные возможности

- **pmuser.mac** — инициализационный макрос, выполняется при старте PowerMill.
  В него добавляют свои дефолтные настройки и параметры.
- **Fix Macros** — *Macro Fixer* обновляет команды старой версии PowerMill
  до валидных в текущей версии (миграция макросов между релизами).
- **Programming Guide** — отдельный PDF Autodesk: переменные, циклы, функции,
  аргументы, ветвления (принятие решений) внутри макросов.

## 5. Что забрать в переработку прототипа ENCY

1. **«Echo/Command log»** — показывать пользователю, какая команда стоит за действием.
   Это повышает доверие и упрощает правку (в прототипе строки сейчас «человеческие» —
   можно дать переключатель «показать команду»).
2. **Полноценный Debugger-режим прогона** вместо простого запуска:
   - несколько breakpoint'ов (не один);
   - «выполнить до breakpoint» (Execute);
   - пошаговый проход (Step);
   - **пропуск шага** (Skip) — прямой аналог Include-галочки Photoshop, но в рантайме;
   - **панель переменных/состояния** справа во время прогона.
3. **Аргументы/параметры макроса** при запуске (`MACRO name arg`) —
   один макрос под разные значения.
4. **Вложенность**: вызов макроса из макроса — переиспользование блоков.
5. **Init-макрос** и **миграция** (Fix) — на будущее, для «взрослой» версии фичи.

| PowerMill | Прототип макросов ENCY |
|---|---|
| `.mac` файл | Макрос в списке (`Macro name N`) |
| Строка-команда | Строка инспектора (событие + параметр) |
| Echo Commands | *(нет)* — кандидат: переключатель «человеко-читаемо / команда» |
| Record / Stop | Кнопки Record / Stop |
| Run | ▶ запуск макроса |
| Debug → Add breakpoint | Точка-брейкпоинт слева |

| Watch variables (правая панель) | *(нет)* — панель состояния во время прогона |
| Аргументы `MACRO x 2` | *(нет)* — параметры запуска |
| Вызов макроса из макроса | *(нет)* — вложенные макросы |
| pmuser.mac | *(нет)* — init-макрос |

## 7. PowerMill vs Photoshop — коротко для дизайн-решения

| Аспект | Photoshop (Actions) | PowerMill (Macros) |
|---|---|---|
| Представление | Визуальный список шагов-объектов | Текстовые команды `.mac` |
| Пауза для пользователя | Modal control (тумблер на шаге) | Breakpoint в **Debugger** |
| Пропуск шага | Include-галочка | Skip next line (в отладчике) |
| Правка параметров | Двойной клик → диалог | Правка текста / echoed-команд |
| Прогон | Play + Playback Options (скорость) | Run / Debug (пошагово) |
| Аудитория | Дизайнер (визуально) | Инженер (командно, с отладкой) |

> Для ENCY (инженерная CAM-аудитория) разумен **гибрид**: визуальный список шагов
> как в Photoshop + серьёзный режим прогона/отладки как в PowerMill
> (несколько breakpoint'ов, пошаговый проход, панель состояния, пропуск шага).
