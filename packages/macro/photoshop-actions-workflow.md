# Макросы в Photoshop (Actions / «Операции») — воркфлоу

> Референс для переработки прототипа макросов ENCY.
> Источник: официальная документация Adobe + разбор панели Actions.
> Собрано: 2026-09-18.

Photoshop-фича называется **Actions** (рус. «Операции»). Её воркфлоу — эталон паттерна
«записал → отредактировал → воспроизвёл» с точками остановки.

---

## 1. Модель данных: 3 уровня

```
Set (набор / папка)  →  Action (операция)  →  Step (команда / шаг)
```

- Операция **всегда живёт внутри набора** — нельзя создать операцию без набора.
  (Отличие от плоского списка макросов в текущем прототипе.)
- Наборы сохраняются в файл `.atn` и передаются между пользователями
  (в ENCY-контексте это может быть «сохранить в проект» / экспорт).

---

## 2. Ключевая находка: у каждого шага ДВЕ колонки-тумблера слева

Это напрямую ложится на «точку слева» в прототипе.

| Колонка | Что делает |
|---|---|
| **1. Include (галочка)** | Включить / исключить шаг из воспроизведения. Снят — шаг пропускается (не удаляется). Если внутри операции есть выключенный шаг — галочка самой операции **краснеет**. |
| **2. Modal control (иконка диалога)** | **Это и есть «брейкпоинт».** На этом шаге операция **останавливается и открывает диалог**, чтобы пользователь ввёл свои значения, затем Enter — продолжение. Если такой шаг есть — иконка операции тоже **краснеет**. |

> Вывод: в Photoshop пауза — **не отдельная сущность, а тумблер на существующем шаге**.
> «Точка-брейкпоинт» из прототипа концептуально = modal control.

---

## 3. Полный воркфлоу

### 3.1. Подготовка
- **New Set** → задать имя набора.
- **New Action** → имя, набор, (опц.) горячая клавиша F2–F12 и цвет для Button Mode.

### 3.2. Запись
- Нажать **Record** → выполнять реальные действия — каждое пишется отдельным шагом
  с **запомненными параметрами**.
- Для того, что не записывается автоматически, — вставлять вручную (см. 3.3).
- **Stop** — закончить запись.

### 3.3. Три способа вставить «неавтоматизируемое»
- **Insert Stop** — пауза с текстовым сообщением-подсказкой («Выделите область кистью»).
  Опция **Allow Continue** добавляет кнопку «Продолжить», если действие не обязательно.
  → В прототипе это баннер «Ожидание действий пользователя ▶».
- **Insert Menu Item** — вставить команду, которая выполнится **без зафиксированных
  значений** (спросит при проигрывании). Отличие от modal control: modal хранит
  записанные значения и даёт их поправить, а Insert Menu Item значений не хранит вовсе.
- **Insert Path** — вставить контур.

### 3.4. Редактирование записанного
- **Раскрыть шаг** (треугольник) — видны записанные параметры
  (двухколоночный инспектор «команда → значение»).
- **Двойной клик по шагу** или **Record Again** — открыть диалог и ввести новые значения.
- **Дозапись**: выделить шаг → Record → новые действия пишутся **после** него → Stop.
- Перетаскиванием менять порядок; drag в корзину — удалить; Alt+drag — дублировать.

### 3.5. Воспроизведение
- **Play** играет с выделенного шага (можно запустить с середины).
- **Cmd/Ctrl + клик по Play** — проиграть **только один** выделенный шаг.
- **Playback Options** — три режима:
  - **Accelerated** — максимально быстро;
  - **Step by Step** — перерисовка после каждого шага;
  - **Pause For N seconds** — пауза между шагами.
- **Button Mode** — операции показываются как цветные кнопки в один клик
  (без внутренней структуры) — быстрый «плеер» для конечного пользователя.

---

## 4. Что забрать в переработку прототипа ENCY

1. **Иерархия Set → Action → Step** вместо плоского списка — если макросов много.
2. **Две колонки-тумблера** на каждом шаге: «включён / исключён» + «пауза (modal)».
   Единственная точка сейчас смешивает роли — стоит развести
   «пропустить шаг» и «остановиться на шаге».
3. **Красный индикатор на уровне макроса**, если внутри есть выключенные шаги или паузы —
   быстрый обзор без раскрытия.
4. **Три типа паузы**: modal (правка значений) / stop с сообщением / menu item —
   сейчас один брейкпоинт, можно обобщить.
5. **Режимы воспроизведения** (быстро / пошагово / с задержкой) и **запуск с выбранного шага**.

## 5. Быстрая карта соответствий Photoshop → прототип ENCY

| Photoshop | Прототип макросов ENCY |
|---|---|
| Set (набор) | *(пока нет)* — кандидат на группировку макросов |
| Action | Макрос в списке (`Macro name N`) |
| Step | Строка инспектора (событие + параметр) |
| Include-галочка | *(пока нет)* — «пропустить шаг» |
| Modal control | Точка-брейкпоинт слева |
| Insert Stop + Allow Continue | Баннер «Ожидание действий пользователя ▶» |
| Record / Stop | Кнопки Record / Stop |
| Play (с шага) | ▶ запуск макроса |
| Playback Options | *(пока нет)* — режимы скорости прогона |
| Button Mode | *(пока нет)* — компактный режим запуска |
